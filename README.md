# Viet-Trung Tran — Academic site

Personal academic website for **Viet-Trung Tran** (SOICT / HUST), hosted at [datalab.vn](https://datalab.vn).

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (fork of Minimal Mistakes).

## Local development

```bash
bundle config set --local path 'vendor/bundle'
bundle install
bundle exec jekyll serve -l -H localhost
```

Open http://localhost:4000
